Download

Per giocare a Midian servono il client di Ultima Online 2D e i file dello shard. Segui i passi in ordine.

Dopo l'installazione, leggi i primi passi.

Requisiti: Windows 10 o Windows 11 a 64 bit. Se all'avvio compare un errore su un file api-ms-win-crt-…dll, installa il pacchetto gratuito di Microsoft Visual C++ Redistributable (64 bit) e riavvia il PC. Hai Windows 7, 8 o 8.1? Usa il pacchetto per Windows 7 più in basso.

1. Client di Ultima Online

  • Client 2D, versione 1.26.04
    È la versione impostata sul server. Altre versioni potrebbero non collegarsi.
    I file di gioco sono già inclusi nel pacchetto qui sotto.

2. File di Midian

  • Pacchetto dello shard
    Mappe, file aggiornati e configurazione per collegarsi a Midian. Contiene il client ClassicUO di Midian e Razor (530 MB).
    Scarica il pacchetto Server di riserva
    Se il primo pulsante non funziona (a volte GitHub ha dei guasti), usa il server di riserva di Midian. Il browser potrebbe avvisare che il download non è protetto: scegli Mantieni. Impronta SHA-256 del pacchetto: f0253025de6002418bb8ff304609a419398480ad9762e630a36cfe175f6b2e85
    Estrai lo zip in una cartella e fai doppio clic su Avvia Midian.bat.
    Aggiornamenti automatici: ogni volta che avvii il gioco, il launcher di Midian controlla i file e scarica da solo quelli nuovi, poi apre il gioco. Il pacchetto si scarica una volta sola. Se l'hai scaricato prima dell'8 novembre 2026, riscaricalo per avere il launcher.

3. Collegarsi

  • Indirizzo del server
    45.13.235.243, porta 2593. È già impostato nel pacchetto: basta avviare il gioco. Se hai scaricato il pacchetto prima del 7 novembre 2026, scaricalo di nuovo.
  • Account
    Puoi crearlo tu: nella schermata di accesso clicca su "Crea un nuovo account" e scegli nome e password. Per qualsiasi problema scrivi allo staff: vedi la pagina Contatti.
Al primo accesso il personaggio tocca la pietra della scelta di razza e classe: prima di decidere leggi la wiki.

Solo per Windows 7, 8 e 8.1

Questo pacchetto è SOLO per chi non ha Windows 10 o superiore. Se hai Windows 10 o 11 usa il pacchetto normale qui sopra: ha più funzioni e si aggiorna da solo.
  • Pacchetto per Windows 7, 8 e 8.1
    Contiene una versione più vecchia di ClassicUO (la 0.1.11, l'ultima che funziona su Windows 7) con Razor, e il client originale di Ultima Online 1.26 di riserva (485 MB).
    Scarica il pacchetto per Windows 7 Server di riserva
    Impronta SHA-256: 9510129fc265b4305757aa05e4d1db91958b8727c2dbaaf9edd7ec83e1c15f35
  • Prima di giocare (una volta sola): installa da Microsoft .NET Framework 4.7.2 o più recente e il Visual C++ Redistributable (64 bit). Servono Windows a 64 bit e, su Windows 7, il Service Pack 1.
  • Come si gioca: estrai lo zip e fai doppio clic su Avvia Midian.bat. Se non parte, prova Avvia client originale.bat (client 1.26, senza Razor).
  • Cosa manca rispetto al pacchetto normale: gli aggiornamenti automatici (quando annunciamo un nuovo pacchetto va riscaricato), la creazione dell'account dal gioco (chiedilo allo staff su Discord, o crealo una volta da un PC con Windows 10/11), la finestra "Effetti attivi" con il pulsante Effetti, e i numeri dei danni sopra la testa.
